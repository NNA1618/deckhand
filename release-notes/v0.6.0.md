Deckhand 0.6 installs from a disk image, updates itself, keeps the Mac awake with the lid closed and fixes the color picker.

## New
- **Updates by themselves.** Deckhand checks for a new version every few hours and installs it when nothing is open, running or timing. Settings → About → Updates has Check Now and both switches; the menu bar menu has Check for Updates. Every update is checked against Deckhand's own signature and keeps the permissions you gave.
- **Disk image.** Download `Deckhand.dmg`, drag Deckhand to Applications.
- **Keep Awake with the lid closed.** Settings → Keep Awake → With the Lid Closed: install the small helper once with your password, then turn on "Also when the lid is closed". Sleep comes back when Keep Awake ends, when Deckhand quits or crashes, and on battery below the level you choose.
- **Music from any app.** The notch and the Music tab now read the system's Now Playing, so podcasts, VLC, IINA, Telegram and video in any browser show up too, with artwork and controls. Music, Spotify and browsers still work the old way when the system source isn't available. Settings → Music shows which source is in use.

## Fixed
- **The color picker could leave the mouse unable to click**, even after Deckhand quit. Deckhand now has its own picker with a magnifier: click to copy the color, Esc or a right click to cancel. It closes by itself after a minute. It needs the Screen Recording permission, like screenshots.

## Install
Download `Deckhand.dmg` below, open it and drag Deckhand to Applications. The first time, macOS says it can't check the app, because Deckhand isn't signed by Apple: click Done, then open System Settings → Privacy & Security and click **Open Anyway**. Or run once in Terminal:
```bash
xattr -dr com.apple.quarantine /Applications/Deckhand.app
```
Updates after this one install by themselves.

macOS asks again for Accessibility and Screen Recording after this update, once: Deckhand now has a stable release signature.
